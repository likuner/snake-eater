# 贪吃蛇游戏

一个使用Python和Pygame开发的经典贪吃蛇游戏，具有精美的视觉效果和流畅的游戏体验。

## 游戏特性

- 精美的图形界面
  - 可爱的蛇头设计，带有动态眼睛
  - 渐变色蛇身，从头部到尾部逐渐变暗
  - 带有高光和绿叶的苹果食物
  - 网格背景，便于定位

- 完整的游戏流程
  - 开始界面，显示游戏说明
  - 游戏进行界面，实时显示分数
  - 游戏结束界面，显示最终得分和操作提示

- 游戏功能
  - 实时得分显示
  - 最高分记录
  - 新纪录提示
  - 碰撞检测（墙壁和自身）

- 独立的界面区域
  - 顶部独立的分数栏（50像素高度）
  - 游戏区域与分数栏完全分离
  - 清晰的视觉分隔

## 系统要求

- Python 3.6+
- Pygame 2.5.0+

## 安装步骤

1. 克隆或下载项目到本地

2. 安装依赖包：
```bash
pip3 install pygame
```

或者使用requirements.txt：
```bash
pip3 install -r requirements.txt
```

## 游戏操作

### 开始游戏
- 在开始界面按任意键开始游戏

### 控制蛇的移动
- ↑ 上箭头键：向上移动
- ↓ 下箭头键：向下移动
- ← 左箭头键：向左移动
- → 右箭头键：向右移动

### 游戏控制
- 空格键：游戏结束后重新开始
- ESC键：退出游戏

## 游戏规则

1. 使用方向键控制蛇的移动方向
2. 吃到红色的苹果食物可以得分并使蛇身变长
3. 撞到墙壁或自己的身体，游戏结束
4. 游戏结束后按空格键可以重新开始
5. 尽可能获得更高的分数

## 技术实现

### 核心模块

1. **初始化设置**
   - 窗口大小：800x600像素
   - 网格大小：20x20像素
   - 游戏速度：每秒5帧
   - HUD高度：50像素

2. **游戏主循环**
   - 持续监听键盘事件
   - 更新游戏状态（蛇的移动、吃食物）
   - 重新绘制画面

3. **蛇的表示**
   - 使用坐标列表存储蛇身体各部分
   - 移动时在头部添加新坐标，尾部删除旧坐标
   - 吃到食物时保留尾部，实现变长

4. **食物生成**
   - 在游戏区域随机位置生成食物
   - 确保食物位置不与蛇身重叠
   - 食物只会在游戏区域内生成

5. **碰撞检测**
   - 检测蛇头是否撞到边界（墙壁）
   - 检测蛇头是否撞到自己的身体
   - 碰撞后显示游戏结束界面

## 视觉设计

### 颜色方案
- 背景色：黑色 (0, 0, 0)
- 蛇头：亮绿色 (50, 200, 50)
- 蛇身：渐变绿色
- 食物：红色 (255, 50, 50)
- HUD栏：深灰色 (30, 30, 30)
- 分数文字：白色 (255, 255, 255)
- 最高分文字：黄色 (255, 200, 0)

### 图标设计
- **蛇头**：圆角矩形，带有白色边框和黑色眼睛
- **蛇身**：圆角矩形，颜色渐变，深绿色边框
- **食物**：圆形苹果，带有高光效果和绿色叶子装饰

## 开发说明

### 修改游戏参数

可以在 `snake_game.py` 文件顶部修改以下常量：

```python
WINDOW_WIDTH = 800      # 窗口宽度
WINDOW_HEIGHT = 600     # 窗口高度
CELL_SIZE = 20          # 网格大小
SNAKE_SPEED = 5         # 游戏速度（每秒帧数）
HUD_HEIGHT = 50          # 顶部分数栏高度
```

### 添加新功能

游戏采用面向对象设计，可以轻松扩展新功能：

- 添加难度级别
- 添加障碍物
- 添加特殊食物（加分、减速等）
- 添加音效和背景音乐
