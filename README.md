# 贪吃蛇游戏

一个经典的贪吃蛇游戏，提供Python和H5两个版本，具有精美的视觉效果和流畅的游戏体验。

## 版本说明

本项目提供两个版本：

### Python版本
- 使用Python和Pygame开发
- 适合桌面端运行
- 功能完整，性能优秀

### H5版本
- 使用HTML、CSS和JavaScript开发
- 可在浏览器中直接运行
- 无需安装任何依赖
- 支持跨平台访问

## Python版本系统要求

- Python 3.6+
- Pygame 2.5.0+

## Python版本安装步骤

1. 克隆或下载项目到本地

2. 安装依赖包：
```bash
pip3 install pygame
```

或者使用requirements.txt：
```bash
pip3 install -r requirements.txt
```

## H5版本运行方式

### 方法1：本地HTTP服务器（推荐）

在项目目录下执行以下命令：

```bash
python3 -m http.server 8000
```

然后在浏览器中访问：
```
http://localhost:8000
```

### 方法2：直接打开文件

在浏览器中直接打开 `index.html` 文件：
```

```

如果项目已推送到GitHub，可以启用GitHub Pages服务：
1. 进入仓库设置
2. 启用GitHub Pages
3. 选择分支（feat/h5）
4. 通过GitHub URL访问游戏

## Python版本游戏操作

### 开始游戏
- 在开始界面按任意键开始游戏

### 控制蛇的移动
- ↑ 上箭头键：向上移动
- ↓ 下箭头键：向下移动
- ← 左箭头键：向左移动
- → 右箭头键：向右移动

### 游戏控制
- 空格键：游戏结束后重新开始
- ESC键：退出游戏

## H5版本游戏操作

## 游戏规则

1. 使用方向键控制蛇的移动方向
2. 吃到红色的苹果食物可以得分并使蛇身变长
3. 撞到墙壁或自己的身体，游戏结束
4. 游戏结束后按空格键可以重新开始
5. 尽可能获得更高的分数

## Python版本技术实现

### 核心模块

1. **初始化设置**
   - 窗口大小：800x600像素
   - 网格大小：20x20像素
   - 游戏速度：每秒5帧
   - HUD高度：50像素

2. **游戏主循环**
   - 持续监听键盘事件
   - 更新游戏状态（蛇的移动、吃食物）
   - 重新绘制画面

3. **蛇的表示**
   - 使用坐标列表存储蛇身体各部分
   - 移动时在头部添加新坐标，尾部删除旧坐标
   - 吃到食物时保留尾部，实现变长

4. **食物生成**
   - 在游戏区域随机位置生成食物
   - 确保食物位置不与蛇身重叠
   - 食物只会在游戏区域内生成

5. **碰撞检测**
   - 检测蛇头是否撞到边界（墙壁）
   - 检测蛇头是否撞到自己的身体
   - 碰撞后显示游戏结束界面

## H5版本技术实现

### 核心技术

1. **HTML结构**
   - 使用语义化HTML5标签
   - Canvas元素用于游戏渲染
   - 响应式布局设计

2. **CSS样式**
   - 现代化的UI设计
   - 流畅的动画效果（脉冲、发光、庆祝）
   - 渐变色和阴影效果
   - 响应式媒体查询

3. **JavaScript游戏逻辑**
   - 面向对象设计
   - 游戏循环使用requestAnimationFrame
   - 事件监听处理用户输入
   - 本地存储（localStorage）保存最高分

4. **游戏核心机制**
   - 蛇的移动和绘制
   - 食物生成和碰撞检测
   - 游戏状态管理（开始、进行中、结束）
   - 分数计算和记录

### 关键特性

- **Canvas渲染**：使用HTML5 Canvas API进行高性能图形渲染
- **动画效果**：CSS动画实现脉冲、发光、庆祝等效果
- **本地存储**：使用localStorage保存最高分记录
- **响应式设计**：适配不同屏幕尺寸
- **无依赖**：纯原生JavaScript，无需任何外部库

## 视觉设计

### 颜色方案
- 背景色：黑色 (0, 0, 0)
- 蛇头：亮绿色 (50, 200, 50)
- 蛇身：渐变绿色
- 食物：红色 (255, 50, 50)
- HUD栏：深灰色 (30, 30, 30)
- 分数文字：白色 (255, 255, 255)
- 最高分文字：黄色 (255, 200, 0)

### 图标设计
- **蛇头**：圆角矩形，带有白色边框和黑色眼睛
- **蛇身**：圆角矩形，颜色渐变，深绿色边框
- **食物**：圆形苹果，带有高光效果和绿色叶子装饰

## 开发说明

### Python版本修改游戏参数

可以在 `snake_game.py` 文件顶部修改以下常量：

```python
WINDOW_WIDTH = 800      # 窗口宽度
WINDOW_HEIGHT = 600     # 窗口高度
CELL_SIZE = 20          # 网格大小
SNAKE_SPEED = 5         # 游戏速度（每秒帧数）
HUD_HEIGHT = 50          # 顶部分数栏高度
```

### H5版本修改游戏参数

可以在 `game.js` 文件顶部修改以下常量：

```javascript
const CANVAS_WIDTH = 800;
const CANVAS_HEIGHT = 600;
const CELL_SIZE = 20;
const GAME_SPEED = 150;
const HUD_HEIGHT = 50;
```
